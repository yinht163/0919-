# 0919 總召時間軸

尹凰 & 韋程婚禮當天(2026/09/19)用的手機端合併時間軸小工具。純靜態網頁,沒有後端,可以直接放 GitHub Pages。

## 檔案說明

- `index.html` — 主頁面,分成「時間軸」跟「資料」兩個分頁
  - 時間軸:文定+午宴合併時間軸、自動反白現在區塊、打勾確認(存在手機本機)、通知按鈕、編輯模式
  - 資料:花藝確認照片(點圖放大)、招待須知PDF(一鍵開啟)、可搜尋的桌次總表(輸入姓名查座位)
- `manifest.json` / `sw.js` / `icon-192.png` / `icon-512.png` — PWA 相關,讓 iPhone 可以「加入主畫面」變成類 App 圖示
- `assets/` — 資料分頁用到的花藝照片跟招待須知PDF,離線也看得到(已加進 sw.js 快取清單)
- `0919婚禮關鍵時刻提醒.ics` — 7 個不能錯過的關鍵時刻,匯入 iPhone「日曆」App 後會用系統原生通知提醒,當作保底

## 部署到 GitHub Pages(新的獨立 repo)

1. 到 GitHub 建一個新 repo,例如 `wedding-0919-timeline`(可設為 Public 或 Private,Private 需要 GitHub Pages 付費方案才能開啟 Pages,建議先用 Public,反正沒有敏感個資)
2. 在這個資料夾內執行:
   ```
   git init
   git add .
   git commit -m "0919 總召時間軸"
   git branch -M main
   git remote add origin https://github.com/<你的帳號>/wedding-0919-timeline.git
   git push -u origin main
   ```
3. 到 repo 的 Settings → Pages,Source 選 `main` branch、`/ (root)`,存檔
4. 幾分鐘後網址會是 `https://<你的帳號>.github.io/wedding-0919-timeline/`

## 婚禮當天怎麼用

1. 用 iPhone 的 **Safari** 打開網址(一定要 Safari,其他瀏覽器沒有「加入主畫面」)
2. 分享 → 加入主畫面,桌面會多一個「0919總召」圖示
3. 打開後點「開啟提醒」,允許通知權限(這是盡力而為,不保證每次都準時跳出)
4. 另外把 `0919婚禮關鍵時刻提醒.ics` 這個檔案傳到手機(AirDrop / LINE / Email 都可以),點開它,iPhone 會問要不要加入「日曆」,選加入——這 7 個關鍵時刻就會用系統原生提醒通知妳,比較不會漏

## 修改 / 新增功能

右上角有「編輯」按鈕,點下去進入編輯模式:

- 每個項目的文字、每張卡片的時間都變成可以直接改的欄位,改完會自動存起來
- 每個項目旁邊有「隱藏」,原本流程表上的項目如果取消了可以先隱藏,不會真的刪掉,編輯模式下方會列出「已隱藏項目」可以還原
- 卡片列表最下面有「＋ 新增」表單,可以加當天臨時冒出來的新事項(選文定/午宴/自訂分類),自訂項目旁邊按鈕是「刪除」可以直接移除
- 最下方有「重設所有修改」,可以一鍵把改過的文字、時間、隱藏、新增全部還原成原始流程表(打勾狀態不會被清掉)

這些修改一樣只存在這支手機、這個瀏覽器裡。

## 已知限制

- 打勾狀態只存在當下這支手機、這個瀏覽器裡,清瀏覽器資料會消失,別的裝置看不到
- iPhone 上網頁/PWA 的推播本來就不是 100% 穩定,`.ics` 日曆提醒是真正的保底
